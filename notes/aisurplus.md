# Surplus / aisurplus.io: рынок инференса и выплаты сид-холдерам

Источник: сообщение от 2026-10-21 + https://aisurplus.io/rankings

## Что это

- Маркетплейс инференса: покупатели присылают запросы, продавцы подключают
  свои ChatGPT, Grok Build или Kimi Code seats.
- API совместим с OpenAI и Anthropic: меняешь base URL и модель, SDK остаётся.
- Модели пула: GPT-6 Luna, GPT-5.6 Sol, GPT-6 Astra, GPT-5.6 Terra,
  GPT-5.6 Luna, GPT Image и другие.
- Для продавцов: каждый обслуженный запрос зачисляется в заработок, seat можно
  поставить на паузу или отозвать.
- Есть $SURPLUS, стейкинг, Astra и обещание «доллар API-использования в день».

  ($32,27 тыс.); цифры не гарантируют доход.

- $SURPLUS и Astra — отдельные токен-механики, требуют отдельного разбора.
